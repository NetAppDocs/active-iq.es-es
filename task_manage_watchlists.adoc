= Administrar una lista de seguimiento en Digital Advisor
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puede ver el panel de control de diferentes listas de observación, editar los detalles de una lista de observación existente y eliminar una lista de observación.

.Pasos
. En el panel de la izquierda, selecciona *Listas de seguimiento*.
+
Aparece la pantalla *Administrar lista de observación*.

. Selecciona el nombre de la lista de seguimiento para ver los detalles del panel de control de la lista de seguimiento.
. Selecciona *Editar* para actualizar los detalles de la lista de seguimiento.
. Selecciona *Eliminar* para eliminar la lista de seguimiento.
